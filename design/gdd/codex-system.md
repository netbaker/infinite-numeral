# 数字神话图鉴系统 GDD（Codex System）

> **系统代号**：Codex
> **优先级**：P2
> **版本**：v2.0 RC
> **依赖系统**：PrestigeSystem、ExpansionSystem、TranscendSystem、DimensionSystem、EntropySystem、GeneSystem、EventSystem、ArchiveSystem
> **设计日期**：2026-07-01

---

## 1. 系统概述

数字神话图鉴是 v2.0 的世界观积累系统。游戏中所有触发过的叙事文本自动收录进图鉴，按四大分类体系组织，构建玩家的"数字宇宙知识库"。部分词条初始为隐藏状态（显示为 `??????????`），需满足特定条件才能解锁，其中"未解之谜"类词条需要跨系统联动解锁。图鉴为玩家提供长线收集目标和世界观深度，让每一次叙事触发都有"我在构建宇宙历史"的意义感。

## 2. 核心机制

### 2.1 词条分类体系

| 分类 | 图标 | 主题色 | 词条范围 | 预估词条数 |
|------|------|--------|---------|-----------|
| 起源传说 | 📖 | 金色 `#ffd700` | 宇宙起源、数字诞生、纪元形成、维度创世 | ~15 条 |
| 宇宙事件 | ⚡ | 橙色 `#ff8844` | 熵崩、维度切换、事件系统、大崩塌、临界爆发 | ~20 条 |
| 先贤记录 | 🧬 | 紫色 `#aa66ff` | 基因突变/重组、飞升叙事、里程碑、档案馆快照 | ~18 条 |
| 未解之谜 | ❓ | 青色 `#44ddff` | 跨系统联动解锁的隐藏词条，需特定条件组合触发 | ~12 条 |

### 2.2 自动收录规则

叙事文本触发时，系统自动检查是否有关联的图鉴词条。如果词条尚未收录，则收录并通知玩家。

#### 2.2.2 收录流程

```
叙事文本触发
    ↓
CodexSystem.onNarrativeTriggered(source, narrativeText)
    ↓
查找 narrativeText 关联的 CodexEntry（通过 source + text hash 匹配）
    ↓
如果词条存在且未收录 → 标记为已收录 + 通知玩家（"📖 图鉴更新：{词条标题}"）
如果词条不存在 → 忽略（非所有叙事都有图鉴词条）
如果词条已收录 → 忽略（去重）
```

### 2.4 词条状态

| 状态 | 展示 | 说明 |
|------|------|------|
| 未收录 | 不显示 | 词条存在于系统但从未触发对应叙事 |
| 已收录 | 正常显示标题+正文 | 触发过对应叙事，内容可见 |
| 隐藏（未解之谜） | `??????????` | 条件未满足，仅显示标题的模糊化版本或提示语 |
| 已解锁（未解之谜） | 正常显示 | 跨系统条件满足后解锁，内容可见 |

### 2.5 词条正文格式

每条词条包含：
- **标题**：6-12 字，诗意化命名
- **分类标签**：起源传说/宇宙事件/先贤记录/未解之谜
- **正文**：2-4 段叙事文本，每段 50-100 字
- **收录时间**：首次收录/解锁的时间戳
- **关联来源**：触发的系统名称（如"PrestigeSystem"、"跨系统联动"）
- **关联条件**（仅未解之谜）：解锁条件的文字描述

## 3. 数据结构

### 3.1 TypeScript 接口定义

```typescript
/** 图鉴分类 */
export type CodexCategory =
  | 'origin'       // 起源传说
  | 'cosmic_event' // 宇宙事件
  | 'sage_record'  // 先贤记录
  | 'mystery';     // 未解之谜

/** 图鉴词条静态定义 */
export interface CodexEntryDef {
  /** 唯一标识 */
  id: string;
  /** 标题 */
  title: string;
  /** 分类 */
  category: CodexCategory;
  /** 正文段落列表 */
  content: string[];
  /** 关联叙事来源（用于自动收录匹配） */
  narrativeSource?: string;
  /** 叙事文本哈希（用于精确匹配，可选） */
  narrativeHash?: string;
  /** 未解之谜专属：解锁条件列表 */
  unlockConditions?: CodexUnlockCondition[];
  /** 未解之谜专属：未解锁时的提示语 */
  hiddenHint?: string;
  /** 图标 emoji */
  icon: string;
}

/** 未解之谜解锁条件 */
export interface CodexUnlockCondition {
  /** 条件类型 */
  type:
    | 'dimension_event'    // 在指定维度触发指定事件
    | 'gene_possess'      // 拥有指定基因及等级
    | 'transcend_count'   // 超越次数达标
    | 'prestige_count'    // 坍缩次数达标
    | 'expansion_count'   // 膨胀次数达标
    | 'entropy_collapse'  // 熵崩相关
    | 'archive_count'     // 档案馆快照数
    | 'achievement_all'   // 全成就
    | 'codex_complete'    // 图鉴其他词条全收录
    | 'skin_active'       // 指定皮肤激活
    | 'number_exact'      // 数字精确值
    | 'dimension_mastery' // 维度精通度
    | 'item_used_count';  // 道具使用次数
  /** 条件参数 */
  params: Record<string, unknown>;
}

/** 图鉴词条运行时状态 */
export interface CodexEntryState {
  /** 词条 ID */
  id: string;
  /** 是否已收录/解锁 */
  unlocked: boolean;
  /** 收录/解锁时间戳 (ms) */
  unlockedAt?: number;
}

/** 图鉴整体状态 */
export interface CodexSystemState {
  /** 词条状态映射（与 GameState.codexEntries 对应，对齐 C3） */
  codexEntries: Map<string, CodexEntryState>;
  /** 各分类已收录计数 */
  categoryCounts: Record<CodexCategory, { unlocked: number; total: number }>;
}
```

### 3.2 GameState 新增字段

## 4. 与现有系统的交互点

| 交互系统 | 交互方式 | 触发时机 | 详情 |
|---------|---------|---------|------|
| **PrestigeSystem** | 叙事收录 | Prestige 叙事触发时 | `CodexSystem.onNarrative('prestige', text)` |
| **ExpansionSystem** | 叙事收录 | Expansion 叙事触发时 | `CodexSystem.onNarrative('expansion', text)` |
| **TranscendSystem** | 叙事收录 + 联动检测 | Transcend 叙事触发时 | 收录叙事 + 检查未解之谜解锁条件 |
| **DimensionSystem** | 叙事收录 + 联动检测 | 维度切换/精通/爆发时 | 收录维度叙事 + 检查如"质数维度+熵崩"等联动条件 |
| **EntropySystem** | 叙事收录 + 联动检测 | 预警/崩塌/道具使用时 | 收录熵崩叙事 + 检查如"0次熵崩"等联动条件 |
| **GeneSystem** | 叙事收录 + 联动检测 | 突变/重组/奇异基因时 | 收录基因叙事 + 检查如"全8类基因"等联动条件 |
| **EventSystem** | 叙事收录 | 事件触发/选择后 | 收录事件叙事 |
| **ArchiveSystem** | 联动检测 | 快照生成/档案馆解锁时 | 检查如"快照≥50"、"档案馆解锁"等联动条件 |
| **SkinSystem** | 联动检测 | 皮肤切换时 | 检查如"二进制脉冲+e100"等联动条件 |
| **showNarration()** | 钩子注入 | 所有叙事触发路径 | 在 gameStore 的 `showNarration()` 中注入 `codexSystem.onNarrative()` 调用 |

### 4.1 集成方式

推荐通过 `gameStore.showNarration()` 统一注入，而非在每个系统中分别调用：

```typescript
// gameStore.ts
function showNarration(texts: string[], duration: number = 3000) {
  // 原有叙事展示逻辑...
  
  // 图鉴收录钩子
  for (const text of texts) {
    codexSystem.onNarrativeTriggered(currentSource, text);
  }
}
```

未解之谜的跨系统联动检测，推荐在以下时机统一检查：
- 每次 Transcend 后
- 每次维度切换后
- 每次熵崩触发后
- 每次基因变化后
- 每次皮肤切换后

## 6. 边缘情况

1. **同一条叙事文本多次触发**：去重——只收录第一次。后续触发不重复收录、不重复通知。
2. **旧存档加载（codexEntries 不存在）**：初始化为空 Map。已有的叙事不会追溯收录，只有未来触发的才会收录（接受信息丢失）。
3. **未解之谜条件在非检查时机满足**：条件满足但未被检测到的情况——在每次 Transcend 后做一次全量条件检查作为兜底。
4. **图鉴词条定义变更（版本更新后新增词条）**：新增的词条状态为"未收录"，不影响已收录词条。删除的词条（如果有）保持已收录状态但内容可能缺失。
5. **隐藏词条的提示语泄露条件**：提示语是模糊化的，不应直接透露具体条件。需策划审核每条提示语。
6. **全收录达成**：当所有词条（含未解之谜）100% 收录时，触发特殊结局叙事 + 档案馆特殊标记。

## 7. 验收标准

1. 任何叙事触发后，关联的图鉴词条自动收录，右上角显示收录通知
2. 同一叙事重复触发不重复收录
3. 四大分类标签正确切换，各分类进度计数准确
