# 《无限数域》v2.0 大版本更新方案

> **版本代号**：「维度裂变」(Dimensional Fracture)
> **策划日期**：2026-06-01
> **当前版本**：v1.x（因子系统 / 事件系统 / 挑战系统 已完成）

---

## 一、版本定位与核心主题

### 主题：数字宇宙的"深度"

v1.x 建立了游戏的**广度**——三大机制系统让玩家有更多事可做。v2.0 要建立**深度**——让每一个数字、每一次操作背后都有更丰富的战略层。

**设计哲学**：
- 让"怎么玩"比"玩多久"更重要
- 每一次飞升都应该有独特的叙事感
- 引入"选择困境"——鱼与熊掌不能兼得

---

## 二、三大核心系统（主菜）

### 🌌 System A：维度系统（Dimension System）

**概念**：玩家的数字存在于多个平行"维度"中，每个维度有独特的增益规则和资源类型。解锁维度需要消耗 Transcend 获得的最高级别货币。

#### 设计要点
| 维度 | 名称 | 特性 | 专属资源 |
|------|------|------|----------|
| Dim-0 | 基础维度（起始） | 标准规则 | 星尘（已有） |
| Dim-1 | 质数维度 | 数字为质数时，所有生产×3 | 「质核」 |
| Dim-2 | 混沌维度 | 随机倍率（0.5x ~ 5x），高风险高回报 | 「混沌碎片」 |
| Dim-3 | 反熵维度 | 飞升次数越多倍率越高，鼓励深度游玩 | 「熵晶」 |
| Dim-4 | 奇点维度 | 接近奇点（极大数字）时触发"临界爆发" | 「奇点核心」 |

#### 维度切换机制
- 玩家每次 Prestige 可以**在维度间切换**（不是永久解锁）
- 每个维度有独立的「维度精通度」，精通后才能激活被动加成
- 维度碎片可以合成特殊「维度晶体」→ 用于购买跨维度增益

#### 新增 UI
- 左面板新增「维度图谱」区域，可视化5个维度状态
- 当前维度以光晕效果标注，已精通维度显示金色徽章

---

### 🧬 System B：基因进化系统（Gene Evolution System）

**概念**：每次 Transcend 时，数字宇宙"留下基因"，这些基因在下一轮游戏中被继承并进化，形成独特的"数字DNA"。

#### 设计要点

**基因类型（8类）**：
1. `增殖基因` — 影响生产者基础产出
2. `催化基因` — 影响因子发现概率
3. `韧性基因` — 影响飞升后的起点数字
4. `共振基因` — 影响事件发生率和持续时间
5. `突变基因` — 随机效果，每轮随机化（高风险高收益）
6. `记忆基因` — 记录历史最高数字，提供永久加成
7. `纠缠基因` — 影响两个随机选中生产者之间的协同倍率
8. `奇异基因` — 解锁隐藏增益或特殊叙事

**进化机制**：
```
初始基因（随机2-3条）
    → 每次 Prestige 有概率"突变"（改变等级或类型）
    → 每次 Expansion 可以"筛选"（删除一条最弱基因）
    → 每次 Transcend 可以"重组"（合并两条同类基因为升级版）
```

**基因图谱 UI**：
- 类似DNA双螺旋可视化，展示当前基因链
- 每条基因有"表达强度"进度条
- 支持基因槽扩容（消耗奇点核心）

---

### ⚔️ System C：对抗机制——「熵崩」(Entropy Collapse)

**概念**：随着数字持续增长，宇宙「熵值」上升，超过阈值时触发「熵崩」事件——一种强制削弱玩家的负面事件，倒逼玩家进行策略性应对。

#### 设计要点

**熵值增长规则**：
- 每秒数字增长 → 熵值 +少量
- 每次使用大倍率购买（×100/MAX）→ 熵值 +中量
- 每次 Prestige → 熵值清零（这是重置的新激励！）

**熵崩效果（3个等级）**：
| 熵值区间 | 状态 | 效果 |
|---------|------|------|
| 0-50% | 稳定 | 无影响 |
| 50-80% | 不稳定 | 所有产出 -20%，时间因子效果减弱 |
| 80-100% | 临界 | 产出 -50%，随机一个生产者停机30秒 |
| 100% | 熵崩！ | 触发"大崩塌"事件，强制消耗大量数字 |

**对抗道具**（消耗星尘购买）：
- 「熵稳定剂」— 立即降低20%熵值
- 「时间回溯」— 回退5秒的熵值积累
- 「维度屏障」— 60秒内熵值不上升

**熵值 UI**：底部 BottomBar 新增熵值进度条（蓝→黄→橙→红渐变）

## 三、中量级系统（配菜）

### 🏆 League System：排行与宇宙档案馆

**核心**：本地化的"成就墙"升级版——「宇宙档案馆」。

- 记录玩家所有历史 Run 的关键数据：最大数字、所用时间、使用的维度、触发事件数等
- 每次 Transcend 生成一张「运行快照」卡片，可查看历史
- 档案馆解锁条件：完成5次 Transcend
- 特殊成就：根据档案数据解锁（如"首次在质数维度达到 e100"）

---

### 🎨 Skin System：数字皮肤与视觉主题

**核心**：玩家可以改变数字的"显示风格"和整体UI主题。

**数字皮肤**（影响数字的记谱方式）：
- `科学记数`（默认）：1.23e45
- `工程记数`：1.23×10⁴⁵
- `汉字大数`：1.23京京京...
- `二进制脉冲`：将数字可视化为脉冲波形

**UI主题包**（各需消耗「熵晶」或「奇点核心」解锁）：
| 主题名 | 风格 | 配色 |
|--------|------|------|
| 深空蓝（默认） | 现代科技 | 深蓝 + 青 |
| 质数绿 | 黑客风 | 纯黑 + 翠绿 |
| 混沌橙 | 蒸汽朋克 | 深棕 + 铜橙 |
| 奇点白 | 极简主义 | 纯白 + 金 |
| 熵崩红 | 末日风 | 深红 + 暗紫 |

---

### 📖 Codex System：数字神话图鉴（叙事深化）

**核心**：将游戏中所有触发过的叙事文本收录进「数字神话图鉴」，构建世界观积累感。

- 每条叙事触发后自动收录
- 分类：`起源传说` / `宇宙事件` / `先贤记录` / `未解之谜`
- 部分词条初始为「??????????」，需满足特定条件才能解锁
- 「未解之谜」类词条解锁需要跨系统联动（例：在质数维度触发熵崩时解锁神秘词条）

## 四、游戏节奏重设计

### 当前问题诊断
| 问题 | 描述 |
|------|------|
| 飞升感不足 | Prestige / Expansion / Transcend 三层区分不够清晰 |
| 中期空洞 | 解锁因子之后、第一次 Transcend 之前，内容偏空 |
| 重置动机 | 玩家不主动 Prestige，缺乏"现在重置有价值"的信号 |

### 解决方案

**1. 飞升仪式感强化**
- 每次飞升触发专属过场动画（SVG 粒子效果，0.5-1秒）
- 叙事文本在飞升瞬间全屏显示（而非角落提示）
- 飞升后"遗产"数据用特效展示（这次留下了什么）

**2. 中期内容补充**
- 新增「量级里程碑」奖励（e10, e20, e30... 每个量级给一个小奖励）
- 引入「知识点」系统：达到某量级解锁一条真实数学/物理知识（eg: e23 → 阿伏加德罗常数）
- 让玩家感受到"这个数字在现实中意味着什么"

**3. 重置信号优化**
- 熵值 > 80% 时，界面出现明显的"现在 Prestige 可以获得额外奖励"提示
- 引入「最佳重置窗口」指示器——AI简单计算当前继续vs重置的性价比

## 七、世界观扩充草案

### 新增叙事素材池（示例）

**维度传说**（解锁维度时触发）：
- Dim-1 质数维度：「质数是宇宙最初的语言。在所有数字诞生之前，只有质数存在。你踏入了那个最古老的领域。」
- Dim-2 混沌维度：「混沌不是无序，而是无限可能的叠加态。在这里，每一刻的你都处于同时存在和不存在的边界。」
- Dim-3 反熵维度：「物理学定律说宇宙趋向混乱。但你找到了例外——一个每次涅槃都变得更强的角落。」

**基因突变**（触发时）：
- 「某段基因序列发生了意想不到的变化——这不是错误，这是进化在说话。」
- 「你上一次轮回的记忆渗入了基因。那些数字，它们还记得你。」

**熵崩预警**（熵值80%+）：
- 「宇宙开始疲倦了。无休止的增长需要付出代价。」
- 「感受到那股颤抖了吗？这不是地震——是熵，在推门而入。」

## 八、v2.0 核心体验目标

完成 v2.0 后，玩家应该能感受到：

1. **"每次玩都不一样"** — 不同维度组合 × 不同基因链，让每个 Run 有独特策略
2. **"我在为某件事努力"** — 熵崩倒逼策略，档案馆记录成长，图鉴填充成就感
3. **"这游戏有深度"** — 维度/基因/熵/挑战四大系统交织，上限足够高
4. **"这宇宙是活的"** — 叙事文本、神话图鉴、数字知识点，构建真实感
