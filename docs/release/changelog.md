# 《无限数域》Android Beta 发行说明（玩家版）

> 这是《无限数域》**首个 Android 公开测试版（Beta）**。
> 当前为**仅 Android** 发布，游戏**静音运行（无音频）**，文案为**简体中文**。
> 本说明汇总自 `0.1.0` 以来所有玩家可见的玩法演进：Sprint 5（数字人格 / 印记 / 量级里程碑）、Sprint 6（维度精通 / 协同 / 晶体商店 / 维度成就 / 知识联动），以及 Phase 6 打磨（性能 / 稳定性）。

---

## 🎮 这是什么游戏

《无限数域》是一款**增量（放置）游戏**：点击产生数字 → 购买生产者加速增长 → 触发层层"重置"获得永久增益，在无限大的数字宇宙中不断突破。本次 Beta 已包含完整的**三层嵌套重置循环 + 维度系统 + 基因进化 + 宇宙档案馆 + 数字神话图鉴**。

---

## ✨ 新增内容（玩家可见）

### 三层重置循环（核心玩法）
- **坍缩（Prestige）**：数字足够大时重置，换取**星尘**解锁星尘升级与科技树。
- **膨胀（Expansion）**：积累星尘后二次重置，换取**暗能量**解锁膨胀升级。
- **超越（Transcend）**：积累暗能量后三次重置，换取**奇点**解锁元升级与里程碑全球倍率。
- 跨周目进度永久保留，越玩越强。

### 维度系统（v2.0 核心）
- 5 个维度：**基础 / 质数 / 混沌 / 反熵 / 奇点**，各有专属资源与机制。
- **维度精通**：停留累积精通度，解锁层级奖励（产出 / 资源 / 特殊效果）。
- **跨维度协同**：维度间产生协同增益（S1–S10），组合搭配出新策略。
- **维度晶体商店**：消耗维度晶体购买永久全局加成。

### 熵崩系统（风险与张力）
- 熵值随时间累积，分稳定 / 不稳定 / 临界 / 大崩塌四档。
- 三种道具：**熵稳定剂**（立即降熵）、**时间回溯**（回退熵积累）、**维度屏障**（短时锁熵）。

### 基因进化系统
- 8 种基因（增殖 / 催化 / 韧性 / 共振 / 突变 / 记忆 / 纠缠 / 奇异），构成**基因链**（最多 8 槽）。
- 基因随机突变 / 重组 / 筛选，提供多样化 build。

### 宇宙档案馆（Run 回顾）
- 每次超越记录一局快照（最高数字、维度、熵崩、基因链等）。
- 支持**两局对比**，追踪效率与风格演进。

### 数字神话图鉴（Codex）
- 通过特定玩法触发解锁神秘词条，串联叙事与机制彩蛋。

### 数字人格 & 印记（元进度）
- **数字印记**：跨周目共享货币（总量上限 14），由量级里程碑与档案馆成就发放。
- **数字人格**：行者 / 驯化者 / 编年史家三种人格，可切换激活、等级跨切换保留。

### 皮肤与主题
- 4 种数字显示皮肤：科学记数法 / 工程记数 / 汉字大数 / 二进制脉冲。
- 5 套 UI 主题：深空蓝 / 质数绿 / 混沌橙 / 奇点白 / 熵崩红（实时切换，不刷新）。

### 辅助与体验
- **新手指引**：首次进入的引导流程。
- **离线收益**：离线期间持续累积（回归时结算弹窗）。
- **自动存档**（每 30 秒）+ 手动存读 + **存档导入/导出**。
- **成就系统**（含维度挑战成就 13 条）与**挑战任务**（每日 / 限时 / 里程碑）。
- **移动端适配**：针对 Android 布局重平衡，覆盖安装保留存档。

## 🚀 性能与稳定性（Phase 6 打磨）
- 主循环热路径性能提升 **约 3.46×（−71%）**，长时运行更流畅、更省电。
- 清理技术债、统一语义化主题色（注：主题变量已统一，仍有约 300+ 处散落硬编码色为已知 P0 债，详见 `docs/polish/visual-strategy.md`），**316 项自动化测试全绿（含 29 项新增打磨冒烟）**、类型检查零错误。
- 三轮 Playtest 覆盖核心循环 / 重置 / 精通 / 协同 / 晶体 / 成就 / 图鉴 / 长时运行，红线（单维乘源、数字印记恒为 0、晶体冻结上限）全部守住。

## ⚠️ 已知事项 / 注意事项（Beta 提醒）
- **静音发布**：本版本**无音效与音乐**，属既定设计（非缺陷），后续版本再评估音频。
- **视觉可访问性**：部分界面存在硬编码配色、暂未适配"减少动效"与读屏（ARIA）。不影响游玩，已列入后续优化。
- **数值平衡**：Beta 阶段重点是收集真实玩家的平衡性反馈，部分曲线可能调整。
- **仅 Android**：本次仅发布 Android；桌面 / PWA 不在此版本范围。
- **存档兼容**：升级覆盖安装会保留旧存档；如遇到异常，请用"存档导出"备份后反馈。
