# 《无限数域》v2.0.0 发布说明

🌌 一句话定位：从 v1.0 的"数字堆量"，到 v2.0 的"维度裂变 + 神话图鉴 + 皮肤自由"——你的数域，现在由你定义。

🚀 核心新内容
- 🧬 维度裂变系统：P0/P1/P2 三层循环玩法，维度面板与挑战面板登场，星尘 / 转生（Prestige）让你突破上限、越玩越深。
- 📖 数字神话图鉴 Codex：收录并展示游戏内的数字神话，边玩边解锁你的收藏。
- 🎨 皮肤系统：4 种数字皮肤（科学计数 / 工程记数 / 汉字大数 / 二进制脉冲）+ 5 套 UI 主题（深空蓝 / 质数绿 / 混沌橙 / 奇点白 / 熵崩红），一键切换、实时生效，存档完全兼容。
- 🧭 新手指引：首次进入有引导，上手不再懵。
- 🏆 成就与挑战：成就系统上线，挑战任务反馈更清晰。
- 📱 移动端重制：重平衡"上松下紧"的布局，手机上点得更顺、看得更舒服。

📦 安装 / 升级提示
- 包名：com.infinum.game
- 覆盖安装即可，无需卸载旧版，存档自动保留。
- 复测 APK：infinite_numeral-sprint4-ui-debug.apk（直接覆盖安装本版本即可）。
- 桌面端（Electron）与移动端（Capacitor）表现一致。

⚠️ 已知问题 / 后续
- v2.0.0 是仓库首个正式发布版本（首个 git tag），覆盖从 v1.0 到 v2.0.0 的全部演进。
- 后续版本将继续完善皮肤解锁条件、挑战内容与 Live Ops 活动。

感谢每一位参与复测与反馈的玩家与协作者 ❤️
