# Changelog

本项目 Changelog 按**版本倒序**记录（最新版本在最上方）。

> 说明：v2.0.0 是仓库的**首个正式发布版本（首个 git tag）**。
> 本条目包含从 v1.0（初始提交 `833ae27`，2026-05-22）到 v2.0.0（commit `a4725ee`，2026-07-22）的全部演进，共 30 个 commit。

## [2.0.0] - 2026-07-22

### Added

- **维度裂变核心系统**（`a2b28b5`）：新增 P0 / P1 / P2 三层循环玩法、维度面板（DimensionPanel）、挑战面板（ChallengePanel），以及星尘 / 转生（Prestige）系统。
- **数字神话图鉴系统 Codex**（`e2412ef`）：新增数字神话图鉴，记录并展示游戏内的数字神话内容。
- **皮肤系统**（`57b58a0`）：
  - 4 个数字皮肤：scientific（科学记数法）、engineering（工程记数）、chinese（汉字大数）、binary（二进制脉冲），通过 `Formatter` 零侵入扩展实现。
  - 5 个 UI 主题：深空蓝 / 质数绿 / 混沌橙 / 奇点白 / 熵崩红，基于 CSS 变量切换，运行时即时生效、不刷新页面。
  - 存档兼容，切换皮肤 / 主题**不 bump 版本**。
- **新手指引系统**（`fa74e40`）：新增首次进入游戏的新手指引流程。
- **成就系统与挑战任务反馈**：新增成就解锁与反馈机制，并修复挑战任务反馈相关缺陷（多次 fix）。
- **移动端 UI 重平衡**（`57b58a0` 内 + `4d06ff4` 二次精修）：针对"上半空旷 / 下半紧凑"的布局重平衡，收口子组件样式（`:deep`），抬升间距下限。
- **组件测试**：新增 SkinSelector 组件测试（jsdom 环境，7 例）。测试基线由 222 提升至 229。

### Changed

- **构建 / CI 工程化**：
  - 新增 GitHub Actions APK 自动构建工作流（`b01547a`）。
  - 构建环境升级至 JDK 21（`577881c`）。
  - 提交固定 `debug.keystore`（`02db8fc`），移除 Actions 中动态生成步骤，确保 APK 签名一致。
  - 提交 `package-lock.json`（`b7a2337`），确保 CI 构建依赖版本一致。
  - 优化 GitHub Actions 构建配置与诊断日志（`d8800c2`、`ef931da`、`caaeee2`、`175f0fa`）。
- **代码质量收尾**（`36771d9` + `a4725ee`）：
  - 统一硬编码主题色（科技蓝 `#00bcd4` / chaos 橙 / singularity 金）为语义化 CSS 变量（如 `--color-tech-accent` 等）。
  - SVG 的 `:fill` / `:stroke` 改为 `:style` 绑定，使 `var()` 正确解析。
- **交付物**：APK 已交付用户手机复测（`infinite_numeral-sprint4-ui-debug.apk`，覆盖安装无需卸载、存档保留）。

### Fixed

- 修复图鉴 `mystery` 时序缺陷（批次 1，`0b84700`）。
- 修复维度面板无法关闭的 Bug（`9690d5e`）。
- 修复挑战面板闪退、按钮无反馈，以及 APK 版本号（`v2.0`）（`200b47f`）。
- 修复 `stateVersion` 类型错误与 ChallengePanel 导入错误（`5726392`）。
- 修复膨胀按钮显示条件与点击校验（`a679403`）。
- 修复新手指引无响应与 APK 签名不一致（固定 keystore）（`7663eca`）。
- 修复成就弹窗、解锁逻辑与挑战任务反馈 Bug（多次 fix：`75664b5`、`b38ace2`、`96c5964`）。
- 修复多处 TypeScript 编译错误（维度系统类型修复 `1688c90`，10 个类型错误修复 `9a096eb`、`551f482`）。
- 拆分移动端升级 / 科技页面，修复膨胀、引导、成就相关问题（`2ebdd47`）。
- 对齐 PrestigeSystem 测试到正确实现（阈值 `1e12` / 星尘 ×`0.5`）（`581a1db`）。
- 修复文字选中、底栏 `emit` 等交互问题（`fa74e40`）。
